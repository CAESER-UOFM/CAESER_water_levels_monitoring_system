## 📥 Step 2: Import Your Data

### 🌡️ Start with Barologger Data (Super Important!)
1. 🚀 Go to **Barologger Tab**
2. 🖱️ Click **"Import Barologger Data"**
3. 📁 Select your `.xle` files
4. ✅ Review the data in the preview table
5. 💾 Click **"Save"**

> 💡 **Pro Tip**: Always import barologger data first! It's needed for atmospheric pressure correction.

### 💧 Import Water Level Data
1. 🚀 Go to **Water Level Tab**
2. 🖱️ Click **"Import Water Level Data"**
3. 📁 Select your transducer `.xle` files
4. 🗺️ Map wells to locations (if needed)
5. ✅ Enable barometric compensation
6. 💾 Click **"Import"**

---

## 🚩 Step 3: Quality Control Like a Pro

### 🔍 Review Your Wells
1. 📊 Check the **wells table** in the Water Level Tab
2. 👀 Look for the **User Flag** column (first column)
3. 🎨 You'll see these flag states:
   - 🔘 **Gray**: Not checked yet
   - 🔴 **Red**: Error found 
   - 🟢 **Green**: Approved for use

### 🎯 How to Flag Wells
1. 👆 **Click any flag icon** to cycle through states
2. 💾 **Automatic save** - no extra steps needed!
3. 🔄 **Changes sync** to the cloud for team visibility

### 📈 View Your Data
1. 🎯 **Select wells** in the table
2. 📊 **Plot updates automatically**
3. 🔍 **Zoom and pan** to inspect data quality
4. 🖱️ **Click plot points** for detailed info

---

## 📝 Step 4: Document Your Work

### 📋 Protocol Notes (For Processing Decisions)
1. 🎯 Select a well in the Water Level Tab
2. 🖱️ Click **"Edit Water Levels"**
3. 🧭 Find the **Protocol** section
4. ✍️ Document your processing decisions:
   - *"Applied spike correction to remove 3 outliers on 2024-01-15"*
   - *"Used linear interpolation for 4-hour gap from 08:00 to 12:00"*
   - *"Excluded maintenance period from 2024-03-01 to 2024-03-05"*

### 📝 Well Notes (For Site Context)
1. 🧭 Find the **Notes** section in the same dialog
2. ✍️ Add location-specific observations:
   - *"Well located near irrigation canal, possible summer effects"*
   - *"Site accessible only during dry weather"*
   - *"Transducer depth: 15 ft, total depth: 45 ft"*

## 🌡️ Step 5: Master Baro Magic

### 🎯 What is Master Baro?
Our **Master Baro** is like having a super-smart atmospheric pressure sensor that:
- 🔗 **Combines multiple barologgers** for the best data
- 🎯 **Ensures consistency** across all your wells
- 🔧 **Fills gaps** intelligently
- ⚡ **Optimizes quality** automatically

### ⚙️ Configure Master Baro
1. 🚀 Go to **Barologger Tab**
2. 🖱️ Click **"Edit Master Baro"**
3. ✅ Select which barologgers to include
4. ⚖️ Set weights (higher = more important)
5. 💾 Save your configuration

> 🎉 **Cool Fact**: Even with just one barologger, we create a Master Baro for consistency!
