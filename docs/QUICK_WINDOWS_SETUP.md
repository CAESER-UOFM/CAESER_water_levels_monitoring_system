### **⚠️ Why the "Unblock" step?**

Windows automatically blocks ALL downloaded files for security.  
This includes Chrome, Discord, Steam - any software from the internet.  
**This is completely normal and required!**

### **Need detailed help?**
📖 [**Full Visual Guide**](WINDOWS_UNBLOCK_GUIDE.md) with screenshots and troubleshooting

**🎯 Quick Help:**
- **Don't see "Unblock"?** → File might already be unblocked, try installing anyway
- **SmartScreen warning?** → Click "More info" → "Run anyway" 
- **Still stuck?** → [Open a GitHub issue](../../../issues) with a screenshot
