# CAESER Water Levels Monitoring System

## Project Overview
Water level monitoring application with Google Drive integration, database management, and recharge analysis capabilities.

## Current Branch: main

### Current Development Focus: Recharge Integration

The main branch is focused on integrating the recharge calculation system with the core application database and ensuring all components work seamlessly together.

## Development Branches

### `feature/collaborative-proposals` (Completed Feature)
A fully working collaborative proposals system for conflict resolution in cloud database uploads. 

**Status**: ✅ Complete and ready for integration  
**Purpose**: Lightweight change proposals (~50KB) instead of full database uploads (1.4GB)

**Key Features Implemented:**
- Upload conflict detection and resolution
- Visual change comparison with tabbed interface  
- Proposal database creation with only changed records
- Change tracking for water level deletions (fixed 178K records issue)
- Professional UI matching application design

**When to Merge Back:**
- After recharge integration is complete and stable
- When ready to add collaborative features to main release

## Technical Architecture

### Database System
- **SQLite** with memory-optimized settings based on available RAM
- **Connection pooling** for improved performance
- **Change tracking** integrated at model level
- **Cloud synchronization** with Google Drive

### Cloud Integration
- **Service Account Authentication** for reliable API access
- **Progress Tracking** for large file operations
- **Version Management** with conflict detection
- **Draft System** for workflow continuity

### User Interface
- **PyQt5** desktop application
- **Tabbed interface** with modular design
- **Professional styling** with consistent design patterns
- **Progress feedback** for long-running operations
